# AI Sana Challenge Hub — от бизнес-задачи к решению

## Краткое описание

Бизнес описывает задачу для студенческой команды слишком коротко, и студентам трудно понять, за что браться. Проект — MVP-платформа, которая помогает представителю бизнеса превратить черновик потребности в полноценную карточку задачи, оценивает качество её заполнения прозрачным рейтингом и публикует в открытом каталоге, где студенческие команды сами откликаются, а бизнес сам выбирает, с кем работать.

Для кого: представители бизнеса (заказчики задач) и студенческие команды хакатона/трека «Образование».

## Что реализовано

- Ввод черновика бизнес-задачи
- ИИ-анализ черновика и генерация ≥3 уточняющих вопросов по недостающим категориям
- Сборка структурированной карточки задачи из черновика и ответов (без домысливания фактов)
- Детерминированная формула рейтинга (0–100) по 7 взвешенным категориям с расшифровкой баллов
- 4 уровня готовности задачи (черновик / рабочая / готовая / приоритетная)
- _В разработке (следующие коммиты): общий каталог с сортировкой/фильтрами, отклики команд, ручной выбор бизнеса_

## Как работает решение

Сквозной сценарий:

1. **Черновик** — представитель бизнеса вводит краткое описание потребности.
2. **Уточнение** — ИИ определяет недостающие сведения из 7 категорий и задаёт ≥3 уместных вопроса.
3. **Карточка** — из черновика и ответов собирается редактируемая карточка задачи, представитель бизнеса подтверждает.
4. **Рейтинг** — система начисляет баллы (0–100) за полноту карточки по прозрачной формуле, без ИИ, и показывает, что повысит рейтинг.
5. **Каталог** — подтверждённая задача публикуется на позиции, соответствующей рейтингу.
6. **Отклик** — любая студенческая команда просматривает каталог и подаёт предложение (идея, план, срок, ссылка).
7. **Выбор** — бизнес сравнивает отклики и вручную выбирает одну, несколько или ни одной команды; автоматическое назначение запрещено.

## Технологии

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- Claude API (`@anthropic-ai/sdk`, модель `claude-opus-5`) — единственный внешний AI-сервис
- Деплой: Vercel

## Архитектура проекта

```
app/
  page.tsx              — экран ввода черновика и уточняющих вопросов
  api/clarify/route.ts  — вызов Claude: анализ черновика → JSON с вопросами
lib/
  types.ts              — модели Task, TaskCard, Team, TeamResponse
  rating.ts             — детерминированная формула рейтинга (без ИИ)
  prompts.ts            — системные промпты для обеих AI-функций
```

Поток данных: `page.tsx` → `POST /api/clarify` → Claude API (промпт `CLARIFY_PROMPT`) → JSON-ответ парсится и валидируется (≥3 вопроса) → рендерится в UI. Рейтинг считается локально в `lib/rating.ts` по структуре `TaskCard`, ИИ в расчёте баллов не участвует.

## Как проверить решение

1. Открыть главную страницу.
2. Ввести слабый черновик, например: *"Нужно автоматизировать проверку заявок клиентов"*.
3. Нажать «Проанализировать черновик».
4. Получить ≥3 уточняющих вопроса по категориям, которые не раскрыты в черновике (например, данные, критерии успеха, связь с бизнесом).

Если `ANTHROPIC_API_KEY` не задан или неверен — эндпоинт вернёт явную ошибку авторизации, а не тихий сбой (см. обработку в `app/api/clarify/route.ts`).

## Данные и интеграции

- Единственная внешняя интеграция — Claude API (Anthropic).
- Собственные данные не хранятся во внешних БД на этом этапе (см. «Ограничения»).
- Синтетические тестовые наборы (5 черновиков, 5 карточек, 5 профилей команд, 5 откликов) — будут добавлены в `lib/seed.ts` на следующем этапе.

## Ограничения

- Каталог задач, отклики команд и экран выбора бизнеса — в разработке, будут добавлены следующими коммитами до дедлайна.
- Нет персистентного хранилища (БД) — на этапе MVP данные в рамках сессии/памяти процесса, что соответствует ограничению объёма из ТЗ (полноценная инфраструктура не требуется).
- Нет авторизации/ролевой модели — намеренно, согласно ограничению объёма кейса.
- ИИ используется только для анализа черновика и (в разработке) сборки карточки — не участвует в расчёте рейтинга и не выбирает команду за бизнес.
