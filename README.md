# Староста-агент

ИИ-агент, который берёт фото расписания или сообщение из WhatsApp-чата и сам доводит его до результата: записывает в базу, создаёт календарь и уведомляет группу в Telegram. Без ручной перепечатки.

## Проблема

В Казахстане около 600 тысяч студентов и 770 колледжей. Расписание живёт в Excel, чатах и на бумаге. Староста каждую неделю вручную перебивает таблицу в телефон и пересылает по чатам, студенты пропускают изменения, преподаватели ждут в пустых аудиториях. На одну группу это 1–2 часа рутины в неделю, на страну сотни тысяч часов.

## Для кого

- Староста группы: главный пользователь, загружает фото или текст.
- Студенты группы: получают уведомление в Telegram и календарь в телефон.
- Куратор или деканат: видят в базе актуальное расписание всех групп.

## Что делает агент

1. Принимает неструктурированный вход: фото расписания или текст из чата.
2. Сам составляет план из шагов.
3. Распознаёт занятия в структурированный вид: день, время, предмет, преподаватель, аудитория.
4. Проверяет результат: пересечения по времени, пустые поля, формат. При проблемах повторяет распознавание с уточнениями или исправляет сам.
5. Записывает расписание в Supabase.
6. Читает из базы обратно и сверяет количество. При расхождении сохраняет повторно.
7. Создаёт файл календаря .ics с повторяющимися событиями на семестр.
8. Отправляет сообщение в Telegram-группу студентов.
9. Пишет итог. Каждый шаг виден на экране в реальном времени.

## Архитектура

```
Пользователь ──▶ Next.js (app/page.tsx)
                     │  POST /api/agent, поток событий (SSE)
                     ▼
            Агентный цикл (app/api/agent/route.ts)
            Claude Opus 5: план → выбор инструмента → оценка результата → повтор
                     │
        ┌────────────┼──────────────┬──────────────┬──────────────┐
        ▼            ▼              ▼              ▼              ▼
 extract_schedule validate_schedule save_schedule create_calendar notify_group
 (Claude Sonnet 5,  (правила)      verify_saved   (.ics)         (Telegram
  фото или текст,                  (Supabase)                     Bot API)
  structured output)
```

Инструменты лежат в `lib/tools/index.ts`, промпты в `lib/prompt.ts`. Цикл продолжается, пока модель вызывает инструменты, максимум 14 шагов. Ошибка инструмента возвращается модели как `is_error`, и она решает, что делать: повторить, исправить или пойти дальше. Каждый запуск логируется в таблицу `agent_runs`.

Если Supabase или Telegram не настроены, соответствующие инструменты работают в режиме заглушки и явно пишут об этом в лог, демо не падает.

## Демо

Ссылка: https://starosta-agent-oscaraltyn.vercel.app

Сценарий на 2 минуты:
1. Открыть сайт, нажать «Вставить пример» или загрузить фото реального расписания.
2. Нажать «Запустить агента».
3. Смотреть лог: план, распознавание, проверка, запись, сверка, календарь, уведомление.
4. Показать сообщение в Telegram-группе и таблицу в Supabase.
5. Скачать .ics и открыть в календаре телефона.

## Стек

- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
- Claude API через `@anthropic-ai/sdk`: `claude-opus-5` для агента, `claude-sonnet-5` для распознавания
- Supabase (Postgres), Telegram Bot API, iCalendar
- Деплой: Vercel

## Запуск локально

```bash
git clone https://github.com/BAITC-Hacks/hack-422c070c-orta.git
cd hack-422c070c-orta
npm install
cp .env.example .env.local
# вписать ANTHROPIC_API_KEY, остальное по желанию
npm run dev
```

Открыть http://localhost:3000

## Деплой на Vercel

1. На https://vercel.com/new импортировать репозиторий.
2. В Environment Variables добавить переменные из `.env.example`.
3. Нажать Deploy.

Через терминал:

```bash
npm i -g vercel
vercel login
vercel env add ANTHROPIC_API_KEY production
vercel --prod
```

## Переменные окружения

| Переменная | Обязательна | Где взять |
|---|---|---|
| `ANTHROPIC_API_KEY` | да | https://platform.claude.com/settings/keys |
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` | нет | Supabase, Settings, API. Схема таблиц в `supabase/schema.sql` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | нет | @BotFather и id группы |
