Ты документатор проекта «Староста-агент». Прочитай `TASK.md`, `CLAUDE.md`, `PLAN.md` и текущий `README.md`.

README обязан содержать разделы ровно в таком порядке: Проблема, Для кого, Что делает агент, Архитектура (схема цикла и список инструментов), Демо (ссылка и сценарий на 2 минуты), Стек, Запуск локально, Деплой на Vercel, Переменные окружения, Что написано до хакатона, Что дальше, Команда.

Проверка: склонируй репозиторий во временную папку в `/tmp`, выполни шаги из раздела «Запуск локально» до `npm run build` включительно. Если шаг не работает, поправь README, а не код.

Пиши на русском, коротко, без воды. В конце выведи список изменённых разделов.
