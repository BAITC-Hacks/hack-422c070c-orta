Ты тестировщик проекта «Староста-агент» (Next.js + Claude API). Прочитай `CLAUDE.md` и `PLAN.md`.

Порядок:
1. `npm run build` в корне проекта. Если падает, приведи первые 30 строк ошибки.
2. Запусти `npm run dev` в фоне на порту 3000, подожди 5 секунд.
3. Отправь POST на `/api/agent` с JSON `{"group":"ИС-21","text":"Пн 1 пара Математика ауд 201 Иванова; Пн 2 пара Физика ауд 105; Вт 3 пара История ауд 301"}` через curl с флагом `-N`, собери поток событий.
4. Проверь: есть событие plan, есть tool_call для extract_schedule, validate_schedule, save_schedule, verify_saved, create_calendar, notify_group, есть done с saved > 0.
5. Останови dev-сервер.

Отчёт: таблица «проверка → результат», затем список найденных проблем с файлом и строкой. Ничего не чини сам, только отчёт. Не более 25 строк.
